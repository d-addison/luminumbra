## Verdict

**The spec is NOT yet sound enough to fan out. There are four independent BLOCK-class defects that must be fixed first**, and they are not cosmetic — each invalidates a load-bearing premise of the wave. (1) The hydraulic-erosion "pure additive offset" is architecturally false: erosion is a non-local iterative grid sim, so `ErodedHeightOffset` is really a baked grid lookup, and the spec never says how single-point callers (collision, spawn, telemetry) get a consistent offset — a foundational design hole, not tuning. (2) The "one re-bless" sequencing rationale rests on SHIELD-RT parity being the dominant terrain-shape baseline, but many other consumers (WaterSystem, WaterfallDetect with its own visual test, the entire RuntimeScenarioHarness vantage/grass/rim/water selection) read terrain shape and will drift under erosion, making the re-bless broad and non-mechanical. (3) The heightfield-primary tracer is stamped "CONFIRMED" on a CPU-Debug spike with **zero GPU measurement**, an 88% wallclock variance, and a 5x grazing-ray blowup the budget cherry-picks around; step count is not GPU cost, and the spec buries the deciding GPU profile as a sub-bullet with no gate. (4) The spline-hash fold is a hidden THIRD hash-affecting change smuggled into "exactly two bumps," and it re-keys ALL shaped presets, not just erosion ones, with no pinned canonical byte order. Beyond the BLOCKs, the wave is overscoped (≈four independently-hard subsystems serialized, including a froxel volume built for a future wave's only consumer), and the perf budget is published as "ratified" against a Phase 0.3 quiet-machine baseline that is still pending. **Recommendation: split the wave (A1+A2+A0 + a thin GPU-profile spike as Wave A; SHIELD-RT substrate as Wave A.2; froxel + SDF brick clipmap as explicit non-goals), resolve the four BLOCKs, then dispatch.**

## Must-fix before fan-out

1. **[BLOCK #1] Erosion single-point consistency contract.** Specify where the baked offset grid lives and how collision/spawn/telemetry single-point `GetTerrainHeightAt` callers get a consistent offset — or restrict erosion to far-LOD render height with collision/spawn consistency as an acceptance test, or defer erosion to its own wave. The "pure additive offset" framing is architecturally false and must be corrected.
2. **[BLOCK #2] Full terrain-shape re-bless surface.** Enumerate every terrain-shape consumer (WaterSystem, WaterfallDetect + its visual test, RuntimeScenarioHarness vantage/grass/rim/water selectors, MarchingCubes, spawn) in A2 gates; pin sweep vantages to fixed world coords. The "one re-bless" rationale is unsound until this is done.
3. **[BLOCK #3] GPU-profile gate precedes substrate commit.** Add a hard gate: a thin A0/Nsight GPU micro-profile of BOTH tracers (against existing FarLodStore tiles) runs and is reviewed before the substrate/primary path is committed. Remove "CONFIRMED"; mark heightfield-primary PROVISIONAL. Split A3 into A3a (skeleton+profile) / A3b (freeze+selected path).
4. **[BLOCK #4] Spline-hash fold is its own attributable commit.** Split it out (marker 0x05, gated on `shaping_enabled`, landed before the erosion 0x04 bump), pin the canonical spline byte encoding + a known-u64 unit test, and add acceptance checks (shaping-OFF byte-unchanged; shaping-ON changes exactly once). Reconcile with the "exactly two bumps" narrative in §1.
5. **[Scope — strongly recommended] Split the wave.** A1+A2+A0+GPU-profile spike = Wave A; SHIELD-RT substrate = Wave A.2; froxel volume + SDF brick clipmap = explicit NON-GOALS of Wave A. The current wave bundles ≈four independently-hard subsystems behind a hard A3→A2 serialization, several of which (froxel, brick clipmap) are built on spec of a future wave.
6. **[Budget honesty — blocks A3 perf ratification] Land Phase 0.3 first.** The §4 pool cannot be "ratified" without the quiet-machine baseline for existing 6x passes. Make it an A3 entry-gate or downgrade §4 to PROVISIONAL/unratified.

The remaining MAJORs (grazing-ray sizing, temporal-stability gate, substrate cost line items, frozen-API enumeration, Wind-template correction, parity ground-truth leg, hash-gate serialization, halo-test specification, WorldVisualSweep delta scoping, dead-system coupling assertion, fire 2.5D de-risk) should be folded into the revised spec before dispatch but do not individually block the wave once the four BLOCKs and the split are resolved.
