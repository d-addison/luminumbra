## Context
A capable particle pass exists; this spec makes it **richer + scalable + TAAU-ready** without
disturbing the existing emitters or the 600 fps render work.

**Already exists (verify, don't rebuild):** `rendering/passes/ParticlePass.{h,cpp}` — CPU sim up to
65,536 particles (spawn, Euler integrate, age, cull, pack into a persistent-mapped instance buffer),
`glDrawArraysInstanced`; one `magical_particles.{vert,frag}` program (branchy sprite/streak/foam
masks); uniform wind (`set_wind`, `wind_response`) + a single global `impact_plane_y` splash;
half-Lambert + 4-nearest-point-light shading; soft-particle fade. Data: `data/common/particles/*.json`
(ambient_motes, waterfall_spray, weather rain/snow). The hashed surface is ONLY the 36-byte
`EmitterDescriptor` set (`rebuild_emitter_descriptors`/`emitter_descriptor_hash`) — gated by the
`ParticleEmitterDeterminism` byte-equal snapshot.

## Gaps → Goals
- **G1 CPU-only sim @ 65k cap:** per-frame CPU integrate of all particles; no GPU compute, no
  alive/dead list, no indirect draw. The scale ceiling.
- **G2 no motion vectors:** particles write only color into the lighting target → the 600 fps agent's
  TAAU/MV phase has NO particle velocity → ghosting/rejection. (The explicit coordination point.)
- **G3 limited forces:** uniform wind + one global splash plane only; no curl/turbulence, point/vortex/
  drag/per-emitter gravity, no depth-buffer collision.
- **G4 single shader / shape set:** no texture-atlas sampling (`atlas_layer` decoded but unused), no
  flipbook, archetypes (fire/smoke/sparks/magic/dust/leaves) collapse to additive-dot or alpha-streak.
- **G5 crude lighting; no sub-emitters/trails/ribbons; no GPU sort; full-res fill** (fill-rate risk for
  big smoke vs the 0.8 ms budget); **schema lacks** force-field list / atlas+flipbook / sort mode /
  lit flag / sub-emitter refs / drag+gravity / collision flag.

## Non-Goals
Changing the hashed `EmitterDescriptor` surface (keep `ParticleEmitterDeterminism` green, zero re-pin);
owning the TAAU pass (the 600 fps agent does — this track only PROVIDES particle motion vectors per the
agreed contract); putting particle motion into `world_hash` (particle motion stays render-only,
never-hashed — the one-way rule).

## Coordination contract (with the live 600 fps render agent)

## Phasing (each landable + testable; render-only → zero re-pin)
0. **Phase 0 — schema + contract:** pin a v2 emitter schema as a STRICT superset of
   `luminumbra.particle_emitter.v1` (absent fields → current behavior, all existing JSON byte-identical);
   add default-OFF `SystemConfig` flags (GPU backend + motion-vector) under `render.*`; agree the MV
   target format with the 600 fps agent. No behavior change; all gates green.
1. **Phase 1 — CPU force model + archetypes:** extend `EmitterData`/JSON with force fields
   (gravity/drag/curl-turbulence/point/vortex) + atlas/flipbook + lit flag; integrate forces in the
   existing CPU `update()`; add fire/smoke/sparks/magic/dust/leaves JSON + atlas sampling + flipbook in
   the frag shader. Existing v1 emitters byte-identical; descriptor hash unchanged.
2. **Phase 2 — depth collision:** G-buffer-depth collision response in `update()` (reflect/slide),
   per-emitter `collision` flag. Additive.
3. **Phase 3 — motion vectors for TAAU:** per-particle velocity varying + previous-frame clip pos in the
   vert shader; write the velocity MRT when the TAAU flag is on (coordinated). Off → byte-identical.
4. **Phase 4 — GPU compute backend (default OFF):** `particle_emit.comp` + `particle_update.comp` +
   dead/alive-list SSBO pool + `glDrawArraysIndirect` (mirror `FoliagePass`); emit kernel consumes the
   deterministic per-emitter seed; verify visual parity with the CPU path + the 0.8 ms budget; enable
   per-emitter via `SystemConfig` for heavy archetypes (smoke/dust).
5. **Phase 5 — polish at scale:** optional half-res particle buffer for heavy fill; optional bitonic GPU
   sort for correct alpha ordering; trail/ribbon particles for sparks/magic. Each independent.

## Determinism
Particle MOTION is render-only and NEVER enters `world_hash` (one-way rule). The hashed
`EmitterDescriptor` surface is untouched → `ParticleEmitterDeterminism` stays green, **zero re-pin**.
GPU emit kernel must consume the deterministic per-emitter seed for run==replay parity vs the CPU path.
