# Security Policy

## Supported version

Security fixes are made against the latest source on `main`. Older snapshots and
development branches are not supported.

## Reporting a vulnerability

Please use GitHub Private Vulnerability Reporting for security issues. Do not
open a public issue or pull request, and do not include credentials, private
data, or exploit details in public channels.

This is a hobby project, so response times are best-effort. A report should
include the affected revision, impact, reproduction steps, and any suggested
mitigation. Reports unrelated to security will be closed without action.
